# 📈 A股市场交易简报系统

A股市场结构分析工具，从东方财富获取板块数据，自动生成每日交易简报。

## 快速开始

### 运行命令
```bash
python run.py
```

### 输出文件
- 终端：完整的每日市场交易简报
- `data/report.txt`：日报文件存档

## 输出结果解读

```
📊 市场结论
- 市场状态: 主升 (情绪偏强)
- 主线: 通信设备, 元件, 半导体
- 生命周期: 加速期
- 主线强度: 90
- 风险等级: 低风险
- 切换预警: 安全
- 资金迁移: 无明显迁移
- 操作建议: 可积极参与主线板块
```

### 字段说明

| 字段 | 含义 | 说明 |
|------|------|------|
| 市场状态 | 当前市场所处阶段 | 主升/轮动/混沌 |
| 主线 | 连续两天强势的板块 | 资金聚集方向 |
| 生命周期 | 主线所处阶段 | 启动/加速/分歧/退潮 |
| 主线强度 | 0-100评分 | 数值越高趋势越强 |
| 风险等级 | 综合风险评估 | 低/中/高 |
| 切换预警 | 主线稳定性 | 安全/警惕/危险 |
| 资金迁移 | 资金流向变化 | 有无明显迁移 |

## 每日使用流程

1. **运行分析**
   ```bash
   python run.py
   ```

2. **查看结论**
   - 重点看风险等级和操作建议
   - 记录主线板块

3. **制定计划**
   - 低风险 + 安全 → 可以参与
   - 中风险 → 轻仓
   - 高风险 → 观望

## 核心原则

> **不预测，只看结构**

1. **不预测** - 不猜测明天涨跌，只看今天数据
2. **只看结构** - 分析资金在哪里，趋势强不强
3. **跟随主线** - 只做资金聚集的强势板块
4. **控制风险** - 设置止损，不扛单

## 风险提示

- 本系统仅供市场分析参考，不构成投资建议
- 市场有风险，投资需谨慎
- 请根据自身风险承受能力决定是否参与
